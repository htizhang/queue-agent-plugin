# Knowledge Sources and Provenance

The `queue-literature` notes are original, source-grounded summaries. Each
substantive claim cites its scientific source, with a version-specific locator,
in the [source registry](../skills/queue-literature/references/sources.json).
The notes cite papers and textbooks without copying their text.

Each note also states the assumptions under which its results hold. For
example, the [c-mu](../skills/queue-literature/references/policy-c-mu.md),
[generalized c-mu](../skills/queue-literature/references/policy-generalized-c-mu.md),
[SRPT](../skills/queue-literature/references/policy-srpt.md), and
[Gittins](../skills/queue-literature/references/policy-gittins.md) notes state
the model and information assumptions behind each guarantee.

The knowledge base of the earlier QueueResearcher project
(`Efan404/queue-research`) served as a topic inventory for the collection. The
skill's general literature-search, synthesis, and citation guidance is adapted
from K-Dense Scientific Agent Skills;
[NOTICE.md](../skills/queue-literature/NOTICE.md) attributes it and states the
scope of its MIT license.

For coverage, note format, and checks, see the
[local knowledge collection](knowledge-base-expansion.md).
